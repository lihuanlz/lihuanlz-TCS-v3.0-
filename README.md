This deposit provides the analysis code and data workbooks accompanying the manuscript (preprint: ChemRxiv, DOI: 10.26434/chemrxiv-2024-19rj6/v10). 
Contents. (i) 24 self-contained Python scripts reproducing all quantitative results. Every main-text, Extended Data and Supporting Information figures (Figs. 1c,1d, 2a, 2b; Extended Data Figs. 1–5; SI figures in S1c, S2b, S9, S10) are regenerated by its named script. The Supporting Information tables are produced by the corresponding scripts as formatted console output. The remaining scripts are console-only verifications of numerical values quoted in the text — including the 4PL/5PL concentration-error ranges reported in main-text Table 1 (SI_S3_4pl_5pl_verification.py). Several scripts additionally write machine-readable CSV summaries. Script filenames follow the scheme <scope>_<anchor>_<topic>.py with scope prefixes SI_ (SI sections/figures/tables), Main_ (main-text figures), ED_ (Extended Data figures) and SD_ (Supplementary Data workbooks). (ii) Supplementary Data 1–5: analysis workbooks for the five datasets — multi-capacity immunofluorescence global fit (SD1); digitised Yalow & Berson (1960) RIA (SD2); Simoa sβG benchmark (SD3, Rissin et al., 2010); Simoa IL-6 training data and the 34-specimen clinical test set benchmarked against the Roche Cobas ECLIA reference assay (SD4); and dPCR partition data from two foundational studies (SD5). Each workbook contains the raw data, fitted parameter values, bootstrap/MCMC samples and convergence diagnostics. 
Data collection. Immunofluorescence and Simoa IL-6 measurements were performed in the X.Y.'s laboratories; the 34 clinical specimens were de-identified residual samples . The RIA, sβG and dPCR datasets were digitised or reanalysed from the cited original publications. 
Software requirements. Python 3.13 (tested with Python 3.13.9, Anaconda distribution) with standard scientific packages (NumPy, SciPy, pandas, Matplotlib); no proprietary or non-standard dependencies. Each script runs standalone and writes its figure and console output directly.
